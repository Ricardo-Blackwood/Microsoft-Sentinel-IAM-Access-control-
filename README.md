# Microsoft-Sentinel-IAM-Access-control-
 Cybersecurity Project Highlight | Microsoft Sentinel + IAM 

I recently completed a cybersecurity project leveraging Microsoft Sentinel, Microsoft's powerful SIEM solution, to provision Identity and Access Management (IAM) for a user in a secure and efficient way.

 In this project, I:

✅ Provisioned IAM access for a new user

✅ Assigned the Microsoft Sentinel Contributor role

✅ Ensured proper permissions were granted for effective security 

✅ operations without overprovisioning access

This hands-on experience helped deepen my understanding of role-based access control (RBAC) in Microsoft Azure, reinforcing critical principles of least privilege and security best practices.

As I continue growing in cybersecurity, projects like this give me practical insight into enterprise-level security solutions and how to manage them responsibly.
